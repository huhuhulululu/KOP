# 第一阶段：每月 $500

这是**记分板**，不是承诺，也不是现在就能打到的数。

## 现有这套结构的算术（1 张 NVDA 短铁秃鹰）

现场 2026-08-26 拟建仓（bid/ask+$0.05，不是成交）：

- 最大盈利 ≈ **$126.40**
- 最大亏损 **$373.60**（上限 $500）
- 一年 **4** 次财报 → 每月 4/12 = 0.33 次
- **就算从没亏过**：126.40 × 0.33 ≈ **$42 / 月**，到不了 500
- 打平胜率：373.60 / (373.60 + 126.40) ≈ **75%**
- 路径 helped：**2/6 ≈ 33%**（还不是美元胜率）
- 用 33% 估 EV：0.33×126 − 0.67×374 ≈ **−$208 / 笔**

所以：

1. 不把合约加到 12 张去「凑」每月 500。负 EV 放大只是亏得更快。
2. 不把观察名单五只股票一起开。别的名字没有路径样本，`path_n=0` 会关。
3. 不买数据订阅。CBOE 延迟链够记从今往后的纸盘成交。
4. 券商实盘钥匙仍是两把：`ALLOW_LIVE` 和 `AUTO_TRADE`，都是 false。没有券商凭证。可计数成交 < 8。

## 机器现在会做的「实盘」

`python3 -m kop day` 每个交易日：

1. 拉现场门
2. 有仓就按 bid/ask 盯市；碰到 50% 权利金或 T+1 或打到 max loss 就平
3. 门全开、事件已确认、没有持仓：记一笔 **CBOE bid/ask 纸盘成交**（`recorded_bid_ask`）
4. 试图向券商下单 → 被拒，并写下原因

这是能日更的实盘流程。缺的是券商账户和正 EV 证据，不是再写一层花架子。

## 怎样才算第一阶段打到

连续月份里，**费后已实现** ≥ $500，且：

- 成交来自 bid/ask 纸盘或真券商，不是中间价
- 单笔亏损从未超过 $500
- 没有靠加仓、裸卖、五只并行来凑数
